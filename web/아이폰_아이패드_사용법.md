# 아이폰·아이패드 사용법

1. Safari에서 윤서 학습 페이지 주소를 연다.
2. 홈 화면에 바로가기를 만들려면 Safari의 `공유` → `홈 화면에 추가`를 누른다.
3. 메인 화면에서 30개 지문 중 공부할 지문을 고른다.
4. 위쪽의 `원문만`, `직독직해`, `숙어·단어`, `기출·연관 문제` 버튼으로 화면을 바꾼다.

## 학습 상태 선택

- `테스트용`: 숨기기·다시 보이기와 문제 풀이를 부담 없이 시험할 때 사용한다.
- `윤서 실전용`: 윤서가 실제로 공부한 결과를 계속 쌓을 때 사용한다.
- 선택한 프로필의 단어·숙어·문장 숨김과 문제 풀이 결과는 kd6 서버에 자동 저장된다. 아이폰에 별도 설정 파일을 보관하거나 다른 기기에서 가져올 필요가 없다.
- 아이폰과 아이패드에서 같은 프로필을 선택하면 같은 상태를 불러온다.

## 화면별 사용법

- `원문만`: 색이 다른 단어나 숙어를 누르면 뜻이 5초 동안 나타난다.
- `직독직해`: `EASY`는 해석을 바로 보여 주고, `HARD`는 해석 칸을 눌렀을 때만 보여 준다. 쉬워진 문장은 `쉬운 문장 숨기기`로 감출 수 있으며 `문장 숨김 초기화`로 현재 지문의 문장을 모두 복원할 수 있다.
- `단어·숙어`: 숙어가 먼저 나오고 단어가 뒤에 나온다. `알아요`를 누르면 목록에서 숨겨지고, `몰라요`를 누르면 남는다.
- `연관 문제`: 문제를 풀면 정답 여부가 표시된다. 익숙한 문제는 목록에서 숨길 수 있다.

`이 지문 전체 초기화`는 현재 선택한 프로필에서 현재 보고 있는 지문의 상태만 지운다. 다른 29개 지문의 기록은 지워지지 않는다.

인터넷 연결이 없으면 페이지와 서버 저장 기능을 사용할 수 없다.
