# 아이폰·아이패드 사용법

## 가장 간단한 사용 방법

1. `01_fallacy-of-composition.html` 파일 하나만 아이폰 또는 아이패드의 `파일` 앱에 저장한다.
2. 파일을 눌러 연다.
3. 위쪽의 `원문만`, `직독직해`, `단어·숙어`, `연관 문제` 버튼으로 화면을 바꾼다.
4. 단어 옆의 `알아요`를 누르면 그 단어가 사라지고, `몰라요`를 누르면 주황색으로 남는다.

이 HTML 파일에는 글, 디자인과 프로그램이 모두 들어 있으므로 다른 파일을 함께 복사할 필요가 없다. 인터넷 연결도 필요하지 않다.

## 체크 상태 저장

- 별도 config 파일을 직접 만들거나 편집할 필요가 없다.
- 체크 상태는 페이지를 연 브라우저가 해당 기기 안에 자동 저장한다.
- iOS가 웹사이트 데이터를 지우거나 다른 앱·방식으로 파일을 열면 상태가 유지되지 않을 수 있다.

## 다른 기기로 상태 옮기기

1. 기존 기기의 `단어·숙어` 화면에서 `학습 상태 내보내기`를 누른다.
2. 생성된 `윤서영어_학습상태_01.json`을 AirDrop 또는 iCloud Drive로 새 기기에 전달한다.
3. 새 기기에서 학습 HTML을 열고 `다른 기기 상태 가져오기`를 누른다.
4. 전달한 JSON 파일을 선택한다.

JSON 파일은 이때만 사용하는 백업·이동용 파일이다. 평소 학습할 때는 신경 쓰지 않아도 된다.

## 중요한 제한

- 아이폰과 아이패드 사이에서 체크 상태가 자동 동기화되지는 않는다.
- 완전 자동 동기화가 필요하면 이 페이지를 인터넷에 게시하고 사용자 계정 또는 온라인 저장소를 붙여야 한다.
- `파일` 앱의 미리보기 방식에 따라 버튼 동작이나 자동 저장이 제한될 경우, 공유 메뉴에서 Safari로 열거나 정적 웹사이트로 게시하는 방식이 더 안정적이다.
