# 윤서 영어 시험 학습자료 프로젝트

## 원본

- `doc/2026학년도 2학년 기출문제 학습지(2학기 1차 정기시험).pdf`
- 30쪽이며 현재 확인 결과 페이지마다 지문과 문항이 하나씩 있다.

## 재사용 가능한 추출본

- `data/extracted/2026_2학년_2학기_1차/source.json`: 자동 처리에 적합한 페이지별 구조화 원문
- `data/extracted/2026_2학년_2학기_1차/source.md`: 사람이 한 파일로 읽기 쉬운 원문
- `data/extracted/2026_2학년_2학기_1차/pages/NN.txt`: 필요한 지문 하나만 저렴하게 불러올 수 있는 페이지별 원문
- `tools/extract_exam_pdf.py`: PDF가 바뀌었을 때 추출본을 다시 만드는 도구

추출본은 UTF-8이다. 자동 추출 오류 가능성이 있으므로 최종 학습자료를 만들 때는 해당 PDF 페이지 이미지와 한 번 대조한다.

## 시범 학습자료

- `study/01_fallacy-of-composition.md`: 1번 지문의 직독직해, 자연스러운 해석, 문제 풀이, 어휘, 숙어, 문법과 복습 자료

1번 자료를 검토하여 형식을 확정한 뒤 같은 구조로 2-30번을 제작한다.

## 추출 명령

```powershell
python tools\extract_exam_pdf.py `
  'doc\2026학년도 2학년 기출문제 학습지(2학기 1차 정기시험).pdf' `
  'data\extracted\2026_2학년_2학기_1차'
```
